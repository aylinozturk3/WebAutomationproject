##Overview
This project is a Python-based automation project designed to interact with various web platforms using Selenium and Object-Oriented Programming (OOP) principles. 
The project automates tasks such as navigation, video interaction, and login processes across multiple platforms.

##Supported Platforms
This automation framework currently supports: Amazon Video, Warner Turner, Discord, Skype, YouTube Kids, Vimeo, Microsoft Teams, Yahoo Video

##Features
-Modular design using OOP for scalability and maintainability.
-Cross-platform automation for multiple video and communication services.
-Easy integration with new web platforms by extending base classes.
-Selenium-based browser automation for navigating, interacting, and performing user-like actions.
